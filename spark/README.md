# Spark Project

This repository documents my journey of learning Apache Spark. I have explored Spark DataFrames, worked with the Databricks platform, and written ETL jobs integrating multiple data sources.

Throughout this project, I:

Gained hands-on experience with the Databricks platform and worked extensively within notebooks

Developed ETL jobs that successfully integrated data from multiple sources

## Project Summary

This repository contains the scripts, notebooks, and notes from my learning experience. Each file reflects different aspects of working with Spark, covering key challenges, insights, and practical applications.
